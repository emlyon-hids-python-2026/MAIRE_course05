# MAIRE_course05

Short description of the project: what it does and why.

## Installation

```bash
git clone git@github.com:emlyon-hids-python-2026/MAIRE_course05.git
cd MAIRE_course05
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
